# Learn Quantum

Welcome to **Learn Quantum**! This repository is my personal journey into exploring the world of quantum computing. It contains experiments, algorithms, and learning materials I’ve worked on to better understand this exciting field. While it’s primarily for my own learning, I’m sharing it publicly so others can explore, learn, or even contribute!

---

## 🗂️ Repository Structure

### Quantum Programs (`.qs`)
Written in Q# (Microsoft's quantum programming language), these files demonstrate quantum concepts and algorithms:

- **`Bell.qs`**  
  Demonstrates quantum entanglement by creating the Bell state.

- **`DumpMachine.qs`**  
  Uses `DumpMachine` to inspect quantum state information.

- **`Entangled.qs`**  
  Experiments with creating and measuring entangled states.

- **`Main.qs`**  
  The main entry point for running quantum experiments.

- **`Multi-Qubit.qs`**  
  Explores operations on multiple qubits.

- **`RNG.qs`**  
  A simple quantum random number generator (QRNG).

- **`RNGBonus.qs`**  
  A more advanced version of the quantum RNG.

- **`SkewedRNG.qs`**  
  A quantum RNG with skewed probabilities.

- **`Teleport.qs`**  
  Simulates quantum teleportation using entanglement.

- **`Test.qs`**  
  Testing routines for quantum experiments.

---

### Jupyter Notebooks (`.ipynb`)
Interactive quantum experiments and learning materials:

- **`Estimator.ipynb`**  
  Resource estimation for quantum programs.

- **`ShorRE.ipynb`**  
  Demonstrates Shor's algorithm for factoring integers.

- **`Untitled-1.ipynb`**  
  A scratchpad for experiments and prototypes.

### Other Files

## 🔧 How to Use

1. **Set Up the Environment**  
   - Install the [Microsoft Quantum Development Kit](https://learn.microsoft.com/en-us/azure/quantum/install-overview-qdk) to run Q# files.  
   - Use Python 3.x and Jupyter Notebook for `.py` scripts and notebooks.

2. **Run the Files**  
   - Q# files: Run using the Quantum Development Kit.  
   - Python scripts: Execute with `python3`.  
   - Jupyter notebooks: Open them with Jupyter and interact directly.
